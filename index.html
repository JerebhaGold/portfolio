Projects

Authentication System

This project is a secure money transfer application accessible through a web browser, designed for both admin and customer users. Each user has unique login credentials to keep their accounts safe. Customers can register their details using the website, and the admin securely stores this information. To transfer money, customers enter the recipient’s details and the amount to send. Before completing the transfer, the system asks for a thumb impression to verify the customer’s identity. Once the thumb impression matches, the transfer is processed securely. After the transaction, the customer receives an email and SMS notification confirming the transfer.

What I focused on:

  • Developed the frontend interface for both admin and customer views, ensuring a smooth and responsive user experience.
  • Suggesting and helping integrate notification services using Gmail SMTP for email alerts and Vonage API for SMS notifications to keep customers informed after transactions.
